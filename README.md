# Python for Kids: A Beginner's Guide to Learning Coding and Building Fun Projects

A bright, playful, mobile friendly landing page for young coders and the grown ups who guide them. Meet Pip the snake, try a mini code toy that says your name, explore six starter projects, and find every helpful link in one place.

## What is inside the page

* A sticky header with quick navigation and a free demo button
* A hero section with Pip, an animated mascot, and a speech bubble
* A live "make Pip say your name" playground that shows how real Python works
* Four reasons Python is a great first language
* A simple age guide, from block coding to first Python
* Six fun project cards: number guessing game, silly story maker, turtle drawing, rock paper scissors, personal quiz, and a basic calculator
* Tap to open explanations for variables, conditions, loops, lists, and functions, with tiny code examples
* A short section for parents and teachers
* A "Keep exploring" area where every card is a fully clickable link
* A quick answers section and a friendly footer

## How to publish it with GitHub Pages

1. Create a new public repository and upload `index.html` and `README.md`.
2. Open the repository Settings and choose Pages.
3. Under Build and deployment, set the source to "Deploy from a branch".
4. Pick the `main` branch and the `/ (root)` folder, then save.
5. Wait a minute. Your page will appear at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## How to customize it

* Colors live in the `:root` block at the top of the style section of `index.html`.
* Headings use the Fredoka font and body text uses Nunito, both loaded from Google Fonts.
* All text and links are plain HTML, so you can edit them in any text editor.
* The page needs no build step, no framework, and no installation.
